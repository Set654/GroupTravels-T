# Справочник кодов

`iata_locations.json` — сокращённый снимок открытых справочников городов и
аэропортов Travelpayouts. Поле `locations` связывает код с кодом города; у городов
значение совпадает с ключом. Источники и время загрузки записаны в самом JSON.

Справочник используется локально: запрос авиапоиска не делает отдельного сетевого
запроса для проверки кода. Снимок нужно коммитить и включать в развёртывание.
Он подтверждает наличие кода в справочнике источника на дату загрузки, а не
наличие действующего маршрута или доступного тарифа.

Обновление из корня проекта:

```powershell
.\.venv\Scripts\python.exe scripts/update_iata.py
```

Скрипт запрашивает только два фиксированных официальных HTTPS-адреса, не
использует токен и проверяет структуру перед записью. Обновлять при изменениях
справочника/подготовке релиза; обновление не запускается автоматически в сервисе.
