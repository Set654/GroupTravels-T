## Подтверждено ответом Стаса

- [x] GET /internal/flights/search, три параметра, ответ flights[].
- [x] X-Internal-Api-Key; общий секрет хранится в конфигурациях вне репозитория.
- [x] Таймаут C# 30 с и отключённые автоматические редиректы.
- [x] Отсутствие offerId без кэша; будущие кэш и ID — ответственность C#.
- [x] Все ключи полей предложения обязательны; отсутствующие сведения имеют значение null.
- [x] C# нормализует публичные 400/502/503/504; внутренний 401 Python преобразует в 502.
- [x] Для интеграционного тестирования: Europe/Moscow, connect timeout 3 с,
      read timeout 10 с, лимит 4 параллельных поиска на процесс.

Europe/Moscow согласован как временное правило проверки прошедшей даты.
departureDate в ответе остаётся календарной датой в месте отправления;
departureAt с известным смещением переводится в UTC отдельно.

## Совместная приёмка C# / frontend

- [ ] Пользовательский JWT и доступ к поездке проверяются C#.
- [ ] C# валидирует нормализованный ответ и возвращает список на frontend.
- [ ] Отображаются пустая выдача, ошибки и предупреждение о кэшированной цене.
- [ ] Ссылка открывается во внешнем браузере; отсутствующая ссылка обрабатывается.
- [ ] Выбранный рейс вручную сохраняется в Trip_Activity с UTC scheduledAt/null.
- [ ] Сохранённый план не помечается покупкой и не создаёт расход автоматически.
- [ ] Выполнен сквозной прогон с реальным основным C# backend.
